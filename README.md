# Архитектурный маршрут «Советское Сормово»

Интерактивный гид по архитектуре советского Сормова — Telegram Mini App для изучения исторической застройки Нижнего Новгорода.

## О проекте

Учебный проект, представляющий собой интерактивный маршрут по 10 архитектурным точкам Сормовского района Нижнего Новгорода. Приложение позволяет:

- Изучать историю советской архитектуры на примере реальных зданий
- Проходить квизы и зарабатывать баллы
- Отслеживать прогресс прохождения маршрута
- Сохранять результаты между сессиями
- Работать в офлайн-режиме

## Технологии

- **HTML/CSS/JavaScript** — frontend
- **Leaflet.js + OpenStreetMap** — интерактивная карта
- **Telegram WebApp SDK** — интеграция с Telegram
- **Service Worker** — офлайн-режим
- **localStorage** — сохранение прогресса

## Установка и запуск

### Локальная разработка

```bash
# Клонирование репозитория
git clone <repo-url>
cd sormovo-architecture

# Запуск через Python
python -m http.server 8000

# Или через Node.js
npx serve .
```

Откройте `http://localhost:8000` в браузере.

### Telegram Mini App

1. Создайте бота через [@BotFather](https://t.me/BotFather)
2. Настройте Mini App в Bot Settings → Menu Button
3. Укажите URL вашего хостинга (например, GitHub Pages)
4. Добавьте бота в список приложений

## Хостинг

Рекомендуется использовать **GitHub Pages** для бесплатного хостинга:

1. Создайте репозиторий на GitHub
2. Загрузите файлы проекта
3. Включите GitHub Pages в настройках репозитория
4. Укажите URL в настройках Telegram Bot

## Внешняя навигация

Приложение открывает внешние карты для навигации до точки:
- Яндекс.Карты
- Google Maps
- 2ГИС

## Офлайн-режим

Приложение кеширует:
- Все статические ресурсы (HTML, CSS, JS)
- Данные точек маршрута
- Миниатюры изображений

Для полноразмерных изображений показывается заглушка при отсутствии соединения.
